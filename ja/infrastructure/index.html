// インフラストラクチャ

インフラストラクチャ

Cloud Leasing プラットフォームを構成するコンピュート、ストレージ、ネットワーキング各層の技術的概要と、ノードの導入からモニタリングまでの流れをご紹介します。

// プラットフォーム概要

プラットフォームの構成

Cloud Leasing の各ノードは、GPU/CPU コンピュート、NVMe ストレージ、ネットワークインターコネクト、そしてそれらを統合するオーケストレーションソフトウェアという4つの層から構成されています。以下のセクションでは各層を解説し、続いてリース契約から実際のワークロード稼働までの流れ、そして稼働後のモニタリング方法をご紹介します。

// コンピュート

GPU ＆ CPU プラットフォーム

// GPU ファミリー
RTX、A100、H800
ファミリーと構成に応じて、シングル GPU ノード、マルチ GPU ノード、NVSwitch 搭載の 8-GPU HGX プラットフォームとして提供されます。
// CPU プラットフォーム
Intel Xeon / AMD EPYC
ノードは GPU 構成とワークロードに応じたサイジングで、Intel Xeon または AMD EPYC プロセッサーと組み合わされます。
// システムメモリ
DDR5 ECC RDIMM
メモリはノード規模に応じてスケールし、シングルノード構成から 8-GPU プラットフォームの数テラバイト級容量まで対応します。
// ノード規模
シングル GPU からクラスターまで
コンピュートはシングル GPU ノードから 8-GPU HGX プラットフォーム、さらにマルチノードのベアメタルクラスターまで対応します。
// ストレージ

NVMe ストレージアーキテクチャ

// システムストレージ
エンタープライズ NVMe
専用のエンタープライズ NVMe システムドライブが OS とランタイムストレージを担い、データストレージとは分離されています。
// データストレージ
大容量 NVMe
より大容量のエンタープライズ NVMe データドライブがノード規模に応じてスケールし、データセットとチェックポイントの保存を支えます。
// 冗長性
RAID 管理
Broadcom MegaRAID コントローラーが、全ノードのシステムドライブとデータドライブのストレージ冗長性を管理します。
// ネットワーキング

インターコネクト＆ファブリック

// GPU インターコネクト
NVLink / NVSwitch
マルチ GPU プラットフォームにおいて、ノード内の GPU 同士を高帯域・低遅延で接続します。
// クラスターファブリック
InfiniBand / 高速イーサネット
RDMA を介してノードをマルチノードクラスターに接続し、ノード間通信が標準的なネットワークスタックを経由しないようにします。
// DPU オフロード
NVIDIA BlueField-3
HGX およびクラスタープラットフォームにおいて、ネットワーキング、ストレージ、セキュリティ処理をホスト CPU からオフロードします。
// デプロイ

リースから稼働中のワークロードまで

シングルノードの導入はセルフサービス方式です。ノードを選択するだけで、あらかじめランタイムスタックがインストールされた状態でプロビジョニングされます。マルチノードのクラスター導入は、要件ヒアリング、カスタムクラスター設計、プロビジョニング、明確な SLA の設定という構造化されたプロセスに沿って進められます。詳細はエンタープライズ導入プロセスをご覧ください。

// モニタリング

プラットフォームモニタリング

// インフラストラクチャ
継続的モニタリング
コンピュート、電源、冷却、ネットワークの各層を継続的にモニタリングし、環境やハードウェアの問題が稼働中のワークロードに影響を与える前に検知します。
// アクセス＆アクティビティ
継続的な監督
インフラストラクチャとアクセスのアクティビティを継続的にモニタリングし、異常なパターンの早期発見を支援します。
