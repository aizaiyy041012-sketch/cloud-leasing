// 基础设施

基础设施

Cloud Leasing 平台计算、存储与网络各层的技术概览，以及节点从部署到监控的具体流程。

// 平台架构概览

平台是如何构建的

每个 Cloud Leasing 节点都由四层构成：GPU 与 CPU 算力、NVMe 存储、网络互联，以及将这一切协同运转的编排软件。下面各节将逐一介绍这四层，随后说明节点从签约租赁到实际运行工作负载的流程，以及部署后如何进行监控。

// 计算

GPU 与 CPU 平台

// GPU 系列
RTX、A100、H800
根据系列与配置不同，提供单 GPU 节点、多 GPU 节点，以及配备 NVSwitch 的 8-GPU HGX 平台。
// CPU 平台
Intel Xeon / AMD EPYC
节点将 GPU 与 Intel Xeon 或 AMD EPYC 处理器搭配，规格根据 GPU 配置与工作负载而定。
// 系统内存
DDR5 ECC RDIMM
内存容量随节点规模扩展，从单节点配置到 8-GPU 平台的多 TB 级容量均有覆盖。
// 节点规模
单 GPU 到集群
算力覆盖从单 GPU 节点、8-GPU HGX 平台到多节点裸金属集群的全部规模。
// 存储

NVMe 存储架构

// 系统存储
企业级 NVMe
专用企业级 NVMe 系统盘负责操作系统与运行时存储，与数据存储相互独立。
// 数据存储
大容量 NVMe
更大容量的企业级 NVMe 数据盘随节点规模扩展，支撑数据集与检查点存储需求。
// 冗余保护
RAID 冗余管理
Broadcom MegaRAID 控制器在每个节点上统一管理系统盘与数据盘的存储冗余。
// 网络

互联与网络架构

// GPU 互联
NVLink / NVSwitch
在多 GPU 平台上连接节点内的各 GPU，实现高带宽、低延迟通信。
// 集群网络架构
InfiniBand / 高速以太网
通过 RDMA 将节点连接为多节点集群，跨节点流量无需经过标准网络协议栈。
// DPU 卸载
NVIDIA BlueField-3
在 HGX 与集群平台上，将网络、存储与安全处理从主机 CPU 中卸载出来。
// 部署

从签约租赁到运行工作负载

单节点部署为自助式：选择节点后，系统会以预装好运行时软件栈的状态直接完成配置。多节点集群部署则遵循结构化流程——需求咨询、定制集群设计、部署实施，并配有明确的服务等级协议（SLA）。详情请参阅企业级部署流程。

// 监控

平台监控

// 基础设施
持续监控
对算力、供电、散热与网络各层进行持续监控，以便在环境或硬件问题影响到运行中的工作负载之前及时发现。
// 访问与活动
持续监督
对基础设施与访问活动进行持续监督，帮助及早发现异常模式。
