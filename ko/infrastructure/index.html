// 인프라

인프라

Cloud Leasing 플랫폼을 구성하는 컴퓨팅, 스토리지, 네트워킹 계층에 대한 기술 개요와 노드가 배포되고 모니터링되는 방식을 소개합니다.

// 플랫폼 개요

플랫폼 구성 방식

모든 Cloud Leasing 노드는 GPU 및 CPU 컴퓨팅, NVMe 스토리지, 네트워크 인터커넥트, 그리고 이들을 하나로 묶는 오케스트레이션 소프트웨어의 네 가지 계층으로 구성됩니다. 아래 섹션에서는 각 계층을 설명한 뒤, 임대 계약 체결부터 실제 워크로드 실행까지의 과정과 배포 후 모니터링 방식을 소개합니다.

// 컴퓨팅

GPU 및 CPU 플랫폼

// GPU 제품군
RTX, A100, H800
제품군과 구성에 따라 싱글 GPU 노드, 멀티 GPU 노드, NVSwitch를 탑재한 8-GPU HGX 플랫폼으로 제공됩니다.
// CPU 플랫폼
Intel Xeon / AMD EPYC
노드는 GPU 구성 및 워크로드에 맞춰 Intel Xeon 또는 AMD EPYC 프로세서와 결합됩니다.
// 시스템 메모리
DDR5 ECC RDIMM
메모리는 노드 규모에 따라 확장되며, 싱글 노드 구성부터 8-GPU 플랫폼의 수 테라바이트급 용량까지 지원합니다.
// 노드 규모
싱글 GPU부터 클러스터까지
컴퓨팅 규모는 싱글 GPU 노드부터 8-GPU HGX 플랫폼, 멀티 노드 베어메탈 클러스터까지 다양합니다.
// 스토리지

NVMe 스토리지 아키텍처

// 시스템 스토리지
엔터프라이즈 NVMe
전용 엔터프라이즈 NVMe 시스템 드라이브가 OS 및 런타임 스토리지를 담당하며, 데이터 스토리지와 분리되어 있습니다.
// 데이터 스토리지
대용량 NVMe
더 큰 용량의 엔터프라이즈 NVMe 데이터 드라이브가 노드 규모에 맞춰 확장되어 데이터셋 및 체크포인트 저장을 지원합니다.
// 이중화
RAID 관리
Broadcom MegaRAID 컨트롤러가 모든 노드에서 시스템 드라이브와 데이터 드라이브의 스토리지 이중화를 관리합니다.
// 네트워킹

인터커넥트 및 패브릭

// GPU 인터커넥트
NVLink / NVSwitch
멀티 GPU 플랫폼에서 노드 내 GPU 간 고대역폭, 저지연 통신을 연결합니다.
// 클러스터 패브릭
InfiniBand / 고속 이더넷
RDMA를 통해 노드를 멀티 노드 클러스터로 연결하여, 노드 간 트래픽이 표준 네트워크 스택을 우회하도록 합니다.
// DPU 오프로드
NVIDIA BlueField-3
HGX 및 클러스터 플랫폼에서 네트워킹, 스토리지, 보안 처리를 호스트 CPU에서 오프로드합니다.
// 배포

임대부터 워크로드 실행까지

싱글 노드 배포는 셀프서비스 방식입니다. 노드를 선택하면 런타임 스택이 이미 설치된 상태로 프로비저닝됩니다. 멀티 노드 클러스터 배포는 상담, 맞춤형 클러스터 설계, 프로비저닝, 명확한 SLA 설정을 포함한 구조화된 프로세스를 따릅니다. 자세한 내용은 엔터프라이즈 배포 프로세스를 참고하세요.
